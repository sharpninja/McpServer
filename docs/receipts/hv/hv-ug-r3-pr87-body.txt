- Diagnosis (VSTest `--diag` through a diagnosis-only runner; no tracked change): in `ug-r3-win-lane-diag-2`, the testhost log has 361 starts, 360 results and 361 ends. Next to the lost test, xUnit logged "Received unparseable output from test process: waiting for server to start...." followed by the JSON of a test-passed message. All 50 unparseable lines of that run were pg_ctl output.
- Cause: xUnit v3 runs each test project as its own process and sends its messages as JSON lines on that process's standard output. The fixture ran pg_ctl without output redirection, because a pipe hangs the caller, so pg_ctl's lines garbled messages. Only the Windows lane starts pg_ctl.

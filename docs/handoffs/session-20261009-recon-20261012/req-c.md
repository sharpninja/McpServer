## Contradictions

- C1. Memory injection versus Stateless input. FR-MCP-MEMORY-003 (description): "Supported agents SHALL receive active memories at each host-supported request boundary in a deterministic `REQUIRED MEMORIES` block." Architecture: "in `Stateless` mode the model's input for the request is exactly the rendered package plus the current request" (arch:3364), and the sentinel test asserts only that a prior turn is absent (arch:3364). `SourceKind` (arch:373) has no memory kind, so a Stateless request loses the memory block unless P0 adds memories as a mandatory item, keeps the block beside the package, or amends FR-MCP-MEMORY-003 and -007.
- C2. Reviewer effort. FR-MCP-HOSTILEREVIEW-003 AC 4: "A server-owned worker uses the existing agent infrastructure with effective model gpt-6-astra and effort xhigh", enforced at startup ("RequiredEffort must be xhigh", `src/QBrainAi.Services/Options/HostileReviewWorkerOptions.cs:18-19, 81-82@a8d3934b`). Architecture: `ModelGrader:RequiredEffort` default `max` (arch:2350), "default Codex, `gpt-6-astra`, `max`, the plan's HV reviewer" (arch:131). Two option classes now demand different efforts for the same reviewer, and the existing one throws if set to `max`.
- C3. Store-time string rewriting versus hashes. `McpDbContext.PrepareDbFkChanges` runs `SanitizeStrings` on every string property of every added or modified entity (`McpDbContext.cs:1351-1360, 1704-1718@a8d3934b`), which calls `LineSanitizer.Sanitize`, replacing U+2014 and U+2013 with an ASCII hyphen (`src/QBrainAi.Common.AgentCli/LineSanitizer.cs:23-28@a8d3934b`). Architecture: an input's `Content` is stored "exactly as the builder read it after SecretRedactor and before ranking" (arch:2395); file hashes keep "line endings ... as stored" (arch:2403); the response's `ContentSha256` is computed before the insert (arch:2829-2830); `reviewer_turn` compares the verdict block "byte for byte" (arch:2497). Inference: a package input or a rendered package containing either dash replays as `identical: false`; a response containing one is stored with content whose hash differs from `ContentSha256`, so a reviewer hashing what it reads fails `verdict_binding`; a verdict block containing one fails `reviewer_turn`. Requirement and turn hashes read stored rows and are unaffected.
- C4. WorkspaceResolutionBehavior on every command versus workspace-independent dispatch. Architecture: "registered with `AddCqrsBehavior` for every command and query ... Failure: `ClassifiedError` 404 `not_found` with `details.resource` `workspace`" (arch:250). Develop: global memory creates proceed with no workspace (`WorkspaceResolutionMiddleware.cs:17-18, 160@a8d3934b`) and dispatch `RememberMemoryCommand` with `WorkspacePath` empty (`src/QBrainAi.Support.Mcp/Controllers/MemoryController.cs:125, 298-299@a8d3934b`); FR-MCP-MEMORY-001 AC 2 "Global memories ... are not stamped with a workspace owner"; test `Controller_GlobalCreate_EmptyWorkspace_ReturnsCreated` (`tests/QBrainAi.Support.Mcp.Tests/Memory/MemoryGlobalDefaultWorkspaceTests.cs:100@a8d3934b`). Fourteen route prefixes (`/todo`, `/sessionlog`, `/requirements`, `/context`, and others) also pass through with an empty context (`WorkspaceResolutionMiddleware.cs:32-46`). Inference: in the production composition the behavior refuses these; the cited unit test uses its own dispatcher and would not notice. P0 must scope the behavior.
- C5. Workspace failures on REST. Architecture: "every REST error of a unit this plan adds or changes is the `ClassifiedError` problem+json body" and "A workspace that does not resolve is 404 `not_found`" (arch:83); every agent-context unit lists "404 `not_found` (`workspace`)" (arch:2666 and each unit).

## Tests that break or change

Core Pester suites (`plugins/core/test-fixtures/pester/*@a8d3934b`) depend on the workspace-level `current-turn.yaml` (120 references across 7 files) and `session-state.yaml` (61 references), and on the `workflow.sessionlog.beginTurn` verb (47 references). The architecture makes `current-turn.yaml` a read-only legacy file that no verb targets (arch:211, arch:104) and binds every verb through a host session key or the live-session rule (arch:928-948). Every existing verb test that seeds `current-turn.yaml` and passes no host session key will be refused with `host_session_unknown` or `request_unknown` instead of exercising its behavior. The plan budgets refinement for only four files (plan:613) plus the stop-gate files (plan:619).

Failsafe record shape and drain semantics
- `TEST-MCP-REPL-032` `PluginPowerShellRuntime.Tests.ps1:3631@a8d3934b` asserts a rejected record stays, its `drainAttempts` becomes 1, and the drain continues to newer records (`summary.replayed` 2). The architecture stops the drain at the first outage or retryable answer and keeps every later record (arch:1028, arch:1033), stops on a `rejected` receipt (arch:1066), and removes a record on a final server code (arch:1067). Both the "continue past a rejected record" and the attempt counter disappear. Breaks.
- `TEST-MCP-REPL-034` (`:3729`) quarantines a record at the attempt budget; `TEST-MCP-REPL-033` (`:3680`) quarantines malformed records. The architecture has no quarantine or attempt budget anywhere (no match for "quarantin" in arch or plan outside QB-AGENT-001 context). Both break or become context.

Status: Audit complete; memory add/update/delete, server TODO create/update/delete/move, TODO requirements analysis fail-closed gating, TODO projection repair fail-closed gating, requirements whole-document ingest fail-closed gating, TODO execution file-state and plan-expansion mutations, repo.write, prompt-template create/update/delete, requirements repository CRUD/batch/mapping/export writes, session-log submit/open/upsert/dialog/replace/section/item/delete plus applied workspace-stamp repair fail-closed gating, tool registry create/update/delete, context rebuild/website-ingest/sync fail-closed gating, GraphRAG service-boundary fail-closed gating, GitHub/external issue-sync fail-closed gating, federation control-plane fail-closed gating, voice and agent-pool runtime fail-closed gating, typed REPL TODO create/update/delete wiring, and generic REPL context/TODO/federation/keyserver/subscriber fail-closed mutation policy implemented

Requirements: FR-MCP-120, FR-MCP-121, TR-MCP-TXN-001, TEST-MCP-161

## Decision

Federation adapter apply, Memory add/update/delete mutations, server-side TODO create/update/delete/move mutations, repository `repo.write`, prompt-template create/update/delete mutations, requirements repository CRUD/batch/mapping mutations and `GenerateAll`/`GenerateWiki` export writes, TODO execution file-state and plan-expansion mutations, session-log submit/open/upsert/dialog/replace/section/item/delete, tool registry create/update/delete, and typed REPL TODO create/update/updateSelected/delete/deleteSelected workflow mutations are wired through the turn transaction coordinator in the current transaction slices. Generic REPL `client.context.*`, `client.todo.*`, `client.federation.*`, `client.keyServer.*`, `client.subscriber.*`, direct `IGenericClientPassthrough`, and `workflow.todo.analyzeRequirements` paths now fail closed while required transactions are active unless explicitly classified as safe reads. HTTP TODO requirements analysis also fails closed before Copilot/document side effects while required transactions are active. HTTP, stdio, and typed REPL TODO projection repair fail closed before TODO.yaml rewrite side effects while required transactions are active or the coordinator is degraded. Requirements whole-document ingest fails closed before repository reads or parsed document graph mutations while required transactions are active or degraded. Applied session-log workspace-stamp repair fails closed while required transactions are active or degraded, with dry-run repair retained as a read-only diagnostic. Context rebuild, website ingestion, website streaming ingestion, stdio context ingest, and stdio sync-run fail closed before FTS/vector rebuild, outbound website fetch, context document/chunk writes, sync-status writes, GraphRAG trigger indexing, or completed/result stream events execute. GraphRAG mutations fail closed at the final `IGraphRagService` boundary before database, vector-index, backend indexing, or artifact side effects execute. GitHub issue/comment/workflow/token/sync mutations fail closed before GitHub CLI, token-store, local TODO, or remote GitHub side effects while required transactions are active or the coordinator is degraded. Federation control-plane mutations fail closed before registry, topology, token-generation, tunnel-discovery target registration, conflict/ack, or push side effects while required transactions are active or the coordinator is degraded; signed federation envelope intake remains protocol-internal and reaches the transaction-gated federation apply service. Voice and agent-pool runtime mutations fail closed before interactive process, queue, transcript, or pooled-session side effects execute.

Rejected alternative: wrapping every controller action immediately was rejected because the current coordinator needs mutation-specific rollback callbacks, operation-body canonicalization, sequence assignment, and response mapping. Applying it broadly without those decisions would create partial transaction claims and inconsistent compensation behavior.

## REPL Mutation Paths

The typed TODO REPL workflow is transaction-gated for TODO CRUD and fail-closed for projection repair. Current REPL mutation boundaries are:

- `src/McpServer.Repl.Core/ReplCommandDispatcher.cs`: generic context/TODO/federation/keyserver/subscriber client mutation policy is in place; future slices may replace fail-closed protected-client blocks with domain-specific coordinator compensation where needed.
- Dedicated workflow mutations for remaining requirements ingest namespaces. Memory add/update/remove, repo write, prompt-template create/update/delete, requirements repository create/update/delete/export writes, session-log write tools, and tool registry create/update/delete route through HTTP/service gating in typed or stdio paths where they use the decorated domain services.
- Server-side TODO create/update/delete/move are wired only for providers that expose truthful rollback compensation capability where rollback is required and reject ISSUE-backed mutations while GitHub side-effect compensation remains deferred. TODO execution file-state mutations are wired through state-snapshot rollback, while `CreateTodosFromPlanAsync` additionally preflights legacy TODO compensation, deletes created legacy TODO rows, and restores the captured state snapshot on rollback. Complete isolation against concurrent updates between local mutation and delayed rollback is deferred until a provider transaction or optimistic lease spans coordinator commit settlement.
- Future `workflow.graphrag.*` mutations if that namespace is activated.

## Explicitly Deferred

These surfaces are deferred rather than wired through this coordinator slice:

- Transaction infrastructure endpoints: keyserver party registration/signing and subscriber commit/abort. Gating these through the coordinator would recurse through the dependencies the coordinator itself requires; generic user-callable client passthrough blocks these mutation methods while required transactions are active.
- Tool bucket add/remove/install/sync orchestration while required mutation gating is active. These paths combine bucket state, GitHub manifest reads, registry writes, and provenance stamping; they fail closed until one compensation boundary covers the whole orchestration.
- Runtime, external, and server control-plane endpoints still outside this pass: direct agent execution, desktop launch, tunnels, workspace configuration, auth configuration, and server configuration. GitHub integration writes, voice control, and agent-pool control are now explicitly fail-closed while required turn transactions are active until full remote/runtime-side compensation is designed.

## Next Wiring Slice Criteria

A future wiring slice must add tests first for one domain at a time. Each domain must prove:

- The mutation callback does not run before manifest signing succeeds.
- A committed-success response is not returned before subscriber acknowledgement.
- Post-mutation subscriber failure invokes domain rollback compensation when available.
- Rollback audit is additive and does not delete sign, verify, commit, reject, abort, degraded, or rollback records.
- Degraded mode blocks further mutating responses unless the endpoint is explicitly allowlisted as health, status, or context read behavior.
